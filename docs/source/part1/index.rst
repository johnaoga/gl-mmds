Vue d'ensemble
==============

Cette partie pose les bases : ce qu'est le **big data** (les 5V) et pourquoi il
faut **distribuer** le calcul, puis le modèle **MapReduce** qui rend possible le
traitement parallèle de données massives.

Objectifs
=========

À l'issue de cette partie, chaque étudiant.e sera capable de :

* Caractériser le big data par les **5V** et expliquer les défis du calcul distribué
* Décrire le modèle **MapReduce** (map, regroupement par clé, reduce)
* Modéliser des problèmes classiques en MapReduce (word count, produit matrice-vecteur, opérations relationnelles)
